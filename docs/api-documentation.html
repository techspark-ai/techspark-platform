📋 Overview

TechSpark AI Platform provides a comprehensive REST API for integrating AI agents into your applications. All endpoints return JSON responses and support both HTTP and HTTPS protocols.

ℹ️ Base URL: https://api.techspark.ai/v1

API Features

  • RESTful API design
  • JSON request/response format
  • OAuth 2.0 authentication
  • Rate limiting (100 requests/minute)
  • Webhook support for real-time events
  • Comprehensive error handling
  • API versioning (v1, v2, etc.)

Supported Content Types

Content-Type: application/json
Accept: application/json

🔐 Authentication

All API requests require authentication using OAuth 2.0 Bearer tokens.

Getting Started

  1. Create an account on TechSpark AI Platform
  2. Generate API key from dashboard
  3. Include token in Authorization header

Request Header

Authorization: Bearer YOUR_API_TOKEN
Content-Type: application/json

Example Request

curl -X GET https://api.techspark.ai/v1/agents \
  -H "Authorization: Bearer sk_test_1234567890" \
  -H "Content-Type: application/json"
⚠️ Security: Never share your API token. Keep it secret and secure.

💼 Sales Agent API

POST /agents/sales/chat
▼

Description: Send a message to the sales agent and get a response.

Request Body

message string required
Customer message or inquiry
customer_id string
Optional customer identifier
conversation_id string
Optional conversation context

Request Example

{
  "message": "I'm interested in AI solutions for my e-commerce store",
  "customer_id": "cust_123456",
  "conversation_id": "conv_789012"
}

Response

200 OK 
{
  "status": "success",
  "response": "Great! I can help you with AI solutions...",
  "conversation_id": "conv_789012",
  "timestamp": "2026-03-31T10:30:45.123456Z",
  "next_action": "quote_generation"
}
POST /agents/sales/quote
▼

Description: Generate a quote for the customer.

Request Body

customer_name string required
company_name string required
agents_needed array required
Array of agent names: ["Sales AI", "Support AI", etc.]
monthly_volume number
Estimated monthly transactions

Request Example

{
  "customer_name": "John Smith",
  "company_name": "TechStore Thailand",
  "agents_needed": ["Sales AI", "Support AI"],
  "monthly_volume": 10000
}

Response

200 OK 
{
  "status": "success",
  "quote_id": "QT-20260331103045",
  "customer_name": "John Smith",
  "company_name": "TechStore Thailand",
  "monthly_cost": 149.50,
  "annual_cost": 1794.00,
  "estimated_annual_savings": 7176.00,
  "roi_multiplier": "4x",
  "valid_until": "2026-03-31",
  "created_at": "2026-03-31T10:30:45.123456Z"
}

🎧 Support Agent API

POST /agents/support/tickets
▼

Description: Create a support ticket.

Request Body

customer_name string required
email string required
subject string required
description string required
priority string
low, medium, high, critical

Request Example

{
  "customer_name": "Jane Doe",
  "email": "jane@company.com",
  "subject": "Integration issue",
  "description": "Agent not responding to customer messages",
  "priority": "high"
}

Response

200 OK 
{
  "status": "success",
  "ticket_id": "TK-20260331103045",
  "customer_name": "Jane Doe",
  "email": "jane@company.com",
  "subject": "Integration issue",
  "priority": "high",
  "status": "open",
  "created_at": "2026-03-31T10:30:45.123456Z"
}

▼

Description: Get ticket details by ID.

ticket_id string required

  "status": "open",

}

📱 Marketing Agent API

POST /agents/marketing/content
▼

Description: Generate marketing content for social media.

Request Body

platform string required
facebook, instagram, twitter, linkedin
topic string required
tone string
professional, casual, exciting, educational
hashtags boolean
Include hashtags (default: true)

Request Example

{
  "platform": "facebook",
  "topic": "AI agents for e-commerce",
  "tone": "professional",
  "hashtags": true
}

Response

200 OK 
{
  "status": "success",
  "post_id": "POST-20260331103045",
  "platform": "facebook",
  "content": "Every business deserves AI employees...",
  "tone": "professional",
  "created_at": "2026-03-31T10:30:45.123456Z"
}

❌ Error Handling

The API uses standard HTTP status codes to indicate success or failure.

HTTP Status Codes

Code Meaning Description
200 OK Request successful
400 Bad Request Invalid request parameters
401 Unauthorized Missing or invalid authentication
429 Too Many Requests Rate limit exceeded
500 Server Error Internal server error

Error Response Format

{
  "status": "error",
  "error_code": "INVALID_REQUEST",
  "message": "Missing required parameter: message",
  "details": {
    "missing_fields": ["message"]
  }
}

⏱️ Rate Limiting

API requests are rate limited to prevent abuse.

Rate Limits

  • Standard Plan: 100 requests/minute
  • Professional Plan: 500 requests/minute
  • Enterprise Plan: Unlimited

Rate Limit Headers

X-RateLimit-Limit: 100
X-RateLimit-Remaining: 95
X-RateLimit-Reset: 1617216645
⚠️ Note: When rate limit is exceeded, the API returns a 429 status code.

🔔 Webhooks

Webhooks allow you to receive real-time notifications for events.

Supported Events

  • agent.message.received - Agent received a message
  • quote.generated - Quote was generated
  • ticket.created - Support ticket created
  • ticket.updated - Support ticket updated
  • content.published - Marketing content published

Webhook Payload

{
  "event": "agent.message.received",
  "timestamp": "2026-03-31T10:30:45.123456Z",
  "data": {
    "agent_type": "sales",
    "message": "Customer inquiry",
    "conversation_id": "conv_789012"
  }
}

Setup Webhook

  1. Go to Dashboard → Webhooks
  2. Click "Add Webhook"
  3. Enter webhook URL
  4. Select events to subscribe
  5. Save webhook
